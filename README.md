# JavaScript30 на русском языке

Сайт-лендинг для русскоязычной версии популярного челленджа **#JavaScript30** от Уэса Боса.

[Посмотреть сайт](https://javascript30-ru.vercel.app/)

## О проекте

Этот проект представляет собой русскоязычную адаптацию 30-дневного челленджа по программированию на Vanilla JavaScript. Цель челленджа — создать 30 инструментов и приложений за 30 дней без использования фреймворков, библиотек и компиляторов.

## Особенности

- **30 проектов:** От ударной установки до работы с API и веб-камерой.
- **Обучение через практику:** Фокус на работе с DOM, событиями и современным синтаксисом JS.
- **Видео на русском:** Ссылка на плейлист с видеоуроками (субтитрами).
- **Чистый код:** Никаких лишних абстракций, только чистый JavaScript.
